# GeoMonge 3D

Приложение: https://mifiozu.github.io/geomonge-3d/

Готовая PWA-сборка: построения, 2D/3D, настройки и экспорт работают оффлайн после первой полной загрузки. ИИ требует интернета и использует Cloudflare Workers AI с бесплатной дневной квотой.

На Android: открыть сайт в Chrome, дождаться готовности оффлайн-кэша, выбрать «Установить приложение». Установка на физическом телефоне проверяется пользователем.

Исходники переданы владельцу локальным архивом и в этом репозитории не публикуются. GitHub Pages: main, /(root).

Новый домен имеет отдельный идентификатор приложения https://mifiozu.github.io/geomonge-3d/ . Данные старого домена автоматически не переносятся: проекты и наборы настроек можно экспортировать и импортировать в JSON.
